# I-95 Florida: Miami to Jacksonville

Source: OpenStreetMap northbound I-95, imported to `Assets/Resources/Data/Routes/florida_full.json`.
578 km of road, 142 numbered exits, 109 crossing overpasses. Elevation not imported yet because Florida is nearly flat; the Jupiter test stretch has it.

Proposed game length: about 50 km, roughly 25 minutes at highway speed. Game lengths are a starting proposal and get tuned in play.
